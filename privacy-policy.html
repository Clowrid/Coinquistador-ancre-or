Politique de confidentialité

Coinquistador : mission ancre d'or

Dernière mise à jour : 22 mars 2026

ProueStudio (ci-après "nous") développe et publie l'application mobile Coinquistador : mission ancre d'or (ci-après "le Jeu"), disponible sur Google Play et l'App Store. Cette politique de confidentialité décrit comment nous collectons, utilisons et protégeons les informations lorsque vous utilisez notre Jeu.

1. Consentement

Lors de votre première utilisation, le Jeu vous demande votre consentement avant d'activer les publicités personnalisées :

  • Sur iOS : via la demande de transparence du suivi (App Tracking Transparency) d'Apple
  • Sur Android : via un dialogue de consentement dans le Jeu

Vous pouvez modifier ce choix à tout moment via le bouton de confidentialité sur l'écran d'accueil du Jeu (icône bouclier), ou dans les réglages de votre appareil sur iOS.

Si vous refusez, vous verrez des publicités non personnalisées. Toutes les fonctionnalités du Jeu restent disponibles.

2. Données collectées

Nous ne collectons aucune donnée personnelle directement (pas de nom, email, adresse, ni identifiant personnel).

Le Jeu utilise une authentification anonyme via Firebase Auth : un identifiant technique unique est créé automatiquement, sans que vous n'ayez à fournir d'informations personnelles. Cet identifiant permet de sauvegarder votre progression dans les classements. Si vous choisissez un pseudo pour les classements, celui-ci est stocké sur nos serveurs mais ne constitue pas une donnée personnelle identifiable.

Les services tiers intégrés au Jeu peuvent collecter automatiquement certaines données techniques (uniquement si vous avez donné votre consentement pour les publicités personnalisées) :

  • Identifiant publicitaire de l'appareil (GAID sur Android / IDFA sur iOS)
  • Modèle de l'appareil, version du système d'exploitation
  • Données d'utilisation anonymisées (sessions, événements dans le jeu)
  • Adresse IP (utilisée pour la localisation approximative par les services publicitaires)

3. Services tiers

Le Jeu utilise les services tiers suivants, chacun ayant sa propre politique de confidentialité :

Unity Ads (publicités)

Unity Ads affiche des publicités dans le Jeu. Votre choix de consentement est transmis directement au SDK Unity Ads via les métadonnées GDPR et Privacy avant l'initialisation du service. Avec votre consentement, Unity Ads peut collecter des données pour personnaliser les annonces. Sans consentement, seules des publicités non personnalisées sont affichées.

Politique de confidentialité : https://unity.com/legal/privacy-policy

Google Firebase Analytics

Firebase Analytics collecte des données d'utilisation anonymisées pour nous aider à comprendre comment le Jeu est utilisé et améliorer l'expérience de jeu.

Politique de confidentialité : https://firebase.google.com/support/privacy

RevenueCat (achats intégrés)

RevenueCat gère les achats intégrés (notamment la suppression des publicités). Ce service traite les transactions via Google Play ou l'App Store selon votre plateforme, et peut collecter des identifiants d'achat anonymes.

Politique de confidentialité : https://www.revenuecat.com/privacy

4. Stockage local

Le Jeu sauvegarde votre progression (scores, objets débloqués, paramètres) localement sur votre appareil. Ces données ne sont pas transmises à nos serveurs ni à des tiers.

5. Achats intégrés

Le Jeu propose un achat intégré permettant de supprimer les publicités. Cet achat est traité par Google Play (Android) ou l'App Store (iOS) selon votre plateforme. Nous n'avons pas accès à vos informations de paiement.

6. Public visé

Le Jeu est destiné à un public de 13 ans et plus. Nous ne collectons pas sciemment de données auprès d'enfants de moins de 13 ans.

7. Partage des données

Nous ne vendons, n'échangeons ni ne transférons vos données personnelles à des tiers, en dehors des services tiers mentionnés ci-dessus qui sont nécessaires au fonctionnement du Jeu.

8. Sécurité

Nous prenons des mesures raisonnables pour protéger les informations traitées par le Jeu. Cependant, aucune méthode de transmission ou de stockage électronique n'est totalement sécurisée.

9. Vos droits

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : demander quelles données sont collectées
  • Droit de suppression : demander la suppression de vos données
  • Droit d'opposition : refuser le traitement de vos données à des fins publicitaires
  • Désactivation des publicités personnalisées : via les paramètres de votre appareil (Android : Paramètres > Google > Annonces ; iOS : Réglages > Confidentialité et sécurité > Suivi)

10. Modifications

Nous nous réservons le droit de mettre à jour cette politique de confidentialité. Toute modification sera publiée sur cette page avec une date de mise à jour révisée.
